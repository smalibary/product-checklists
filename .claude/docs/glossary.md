# Glossary: the words we share

Claude uses these exact words with Salem, and adds a row the first time a new term is useful.
One line each, plain meaning. Alphabetical. Salem's own words win: if he calls something X, X goes here.

| Word | What it means here |
|---|---|
| Agent | A Claude working on a job. The main agent talks with Salem; helper agents do smaller jobs. |
| Appointment | A visit of a person in care (doctor, clinic) with a day, a place and who takes them; it shows on the Week view, may include the driver's trip, and holds "what the doctor said" afterwards (E19.4). |
| Arrival checklist | The worker's eleven first-month steps (contract, arrival, medical, iqama, insurance, bank, SIM, room, tour, agreement signed, handbook read), each ticked with its date and a note; two tick themselves (E20.1). |
| Ask | Anything Salem says to Claude, written down in a list the moment he sends it; each one stays open until it is done, waiting on him, or cancelled. A standing ask is an ongoing order ("keep working on all screens") that a new issue does not end. |
| Archive | The closed section at the bottom of the board's Progress tab that holds finished tasks, so open work stays on top. |
| Board | The live page at claude.ai with status, questions, versions and the box to tell Claude things. |
| Branch | A separate line of work in git, so unfinished work never mixes into the main version. |
| Check | An automatic test that runs after every edit and reports a broken rule. |
| Care list | The list behind Me's Care row: the children, then the elders, each opening their card (E19.1). |
| Call home | A card on the worker's Me with the time in her home country now and the next stretch that is evening there while she is resting here (E21.4). |
| Carer | A worker who looks after people, not only the house: the housemaid, nanny, driver and other; carers read a child's card (E18). |
| Child | A household member without an email, added by a parent with a name only; joins by QR code, sees only their own chores and points, never money or workers (E17). |
| Commit | Saving a snapshot of the project in git, with a note saying what changed. |
| Contact | A doctor or an emergency contact on a person in care's card: name, speciality or relation, phone; up to eight of each (E19.1). |
| Component inventory | The closed list of components in DESIGN.md. Screens use only these; a new one needs a real reason (R-35). |
| Component | One reusable piece of a screen, like a button, a card or a menu. |
| Component card | One component cut out of a recorded site: its build, look, states, motion and behaviour, kept in the library so an AI can copy it. |
| Recipe | The written steps on a component card that tell an AI how to rebuild that component in our own stack. |
| States | The different looks of one component: normal, hover, pressed, focused, open, loading, disabled, error. |
| Daily report | One report per child per day from the nanny, housemaid or driver: meals, nap, mood, a note and up to four photos; sending it alerts the parents (E18.4). |
| Design file | DESIGN.md, in Google's format: the colours, text styles and components every screen is built from. |
| Dose | One time a medicine is due on one day; the carer taps Given, and a dose 30 minutes late shows on the parents' Home (E18.3). |
| Dock | The bar fixed at the bottom of the app with the five main tabs (Home, Tasks, Shopping, Chat, Me), each an icon and a name. |
| Document wallet | One worker's documents (iqama, passport, visa, contract, insurance, medical check), each with an expiry date, a photo and only the last 4 characters of its number; one expiring within 30 days shows on Home (E20.2). |
| End-to-end encryption | Messages are locked on the sender's phone and only unlocked on the receiver's; the server passing them on cannot read them (how WhatsApp works). |
| Follower | A relative who is invited only to watch the care: sees the children, elders, medicines, readings and appointments, gets the missed-dose alerts, changes nothing and sees no chat, task or money; has just two Dock tabs, Care and Me (E19.5). |
| Git | The tool that keeps every saved version of the project, so nothing is ever lost. |
| Grill | An interview where Claude asks Salem questions until an idea has no open decisions left. |
| Handbook | The house's written how-tos, one page per routine with steps and photos, beside the rules; the worker taps "I read it" on each. |
| Health reading | One measurement of a person in care (blood pressure, sugar, weight or temperature) with its time; past a limit it turns soft red, and it is never a diagnosis (E19.3). |
| Helper | A second Claude session that does one job and reports back. Visible ones appear in Termi's sidebar. |
| Hook | An automatic step Claude Code runs at a set moment, like after every edit or before compacting. |
| House | One home of a household (E11): a family account can hold several; each person sees only the houses they were given, the owner sees all. |
| House switch | The choice at the top of Home, Tasks, Shopping and House rules: one house, or all of them. Hidden when you see only one. |
| Inbox | The folder where Salem drops screenshots and screen picks for Claude to see. |
| Inspect mode | Ctrl+Shift+Space in an app: point at something on screen and Claude receives exactly what it is. |
| Just for me | The worker's private corner on her Me, with a lock and the line "Only you can see this": the Arabic phrases she has met, money sent home, savings goals, notes and mood; the database lets nobody else read it, and deleting her account erases it (E21). |
| Leaving | The checklist for a worker's last days: things returned, final pay, exit visa or transfer, ticket and handover notes, ending with removing her from the household while her records stay (E20.5). |
| Long run | Claude working through the board's tasks on its own for hours, until the time or usage limit you set. |
| Medicine plan | A person's list of medicines with dose, times of day and dates; owner and family write it, carers tap Given (E18.3). |
| MiniChart | A small line of one health reading over the last 30 days, with a soft red dot past a limit (E19.3). |
| Mockup page | The second artifact: shows one decision's mockup; point at anything and it reaches Claude. |
| Mockup | A drawing of screens in HTML, made before building, to compare options for a hard screen decision. |
| Onboarding | The first-time introduction when someone opens the app: a few slides or a setup checklist, so they know what to do. |
| Orchestrator | The main Claude session: talks with Salem, keeps the board current, sends work to helpers. |
| Money home | The worker's own book of what she sent to her family: day, amount in riyals, to whom, how and the fee, with the year's total; private to her (E21.2). |
| Mood check | One optional tap a day on three faces (sad, so-so, good) in the worker's Just for me; her last 30 days show as a line, and only she sees it (E21.5). |
| Pattern sweep | The weekly review where Claude groups repeated mistakes into patterns and proposes a check, rule or lesson for each; the proposals come to you as a board round. |
| Person in care | A child or an elder someone looks after; one card with their name, school, food and doctor, kept in the same record as the diet card (E18). |
| Pocket money | What a parent pays a child for their points, in riyals; only the grown-ups see the riyals (E17.4). |
| Points | What a child earns for a done chore; the parent turns them into pocket money at the household's rate (10 points = 1 riyal at first). |
| ProgressBar | A thin bar that fills as a goal gets closer, with the percent beside it; green when full (E21.3). |
| Primitive | A tier-1 token: a raw value named by what it is (blue-600, 16px). Only roles point at it. |
| Prompt | The message you give Claude. The setup prompt is the one that sets up a new project. |
| Role (token) | A tier-2 token named by what it is for (primary, muted); it points at a primitive. Components use roles. |
| Rule | Something every session must follow. MUST rules only Salem changes; SHOULD rules are defaults. |
| Server | A computer that is always on and online; it holds the shared data and passes messages between phones. |
| Sign-in | How a person proves who they are to the app (phone code, Apple or Google, or a scanned QR code), so they see only their own household. |
| Savings goal | Something the worker is saving for: a name and the amount needed, with each amount she puts towards it and a bar showing how close she is; private to her (E21.3). |
| Space | One part of a house (kitchen, majlis, bedroom 1...), with its own icon and one of ten colours. |
| Skill | A set of steps Claude follows only when that job comes up, like the grill or a mockup. |
| Status line | The rows at the bottom of Claude's window: usage, cost, and the project status. |
| Things given | The list of what the house gave a worker (phone, uniform, key, room things), each with its date; she taps "I received it" herself, and the day each came back is recorded when she leaves (E20.4). |
| Token | A named design value (a colour, a size, a corner). In three tiers: primitive → role → component token. |
| Trial review | One of the three written reviews of a new worker, at 30, 60 and 85 days after she arrived: five points on three levels and a note; the last one ends with keep or not, which only the owner decides. The worker never sees them (E20.3). |
| Version number | The app's number, like 1.04.002: board versions finished . tasks done since . fixes since. Shown at the bottom of Home. |
| Version (v1, v2) | A set of tasks that together make one usable step of the app. |
| Visit | One planned turn of an hourly helper, such as a cleaner: a day, a start time, hours, a price per hour and a checklist (E17.5). |
| Worktree | A separate copy of the project folder for one branch, so two jobs never collide. |
