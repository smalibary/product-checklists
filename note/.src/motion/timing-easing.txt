title: Timing and easing
about: How long each animation takes and how it speeds up and slows down.
## Duration
- Small changes (a toggle, a hover) about 100 to 200 ms | S m3-easing nng-animation-duration
- Medium changes (a menu, a card opening) about 200 to 300 ms | S m3-easing
- Big changes (a full screen) up to about 400 to 500 ms, never longer without a reason | S m3-easing carbon-motion
- Things leaving faster than things arriving | S m3-easing fluent-motion
- Bigger distance, slightly longer time | S m3-easing carbon-motion
## Easing
- Ease-out for things entering, ease-in for things leaving, standard for moves on screen | S m3-easing mdn-easing
- No linear easing for movement, except progress and spinners | S mdn-easing carbon-motion >motion/loading-motion
- A small named set of curves used everywhere | S m3-easing fluent-motion
