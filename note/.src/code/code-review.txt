## Reviewer
- Checks design, behaviour, tests, naming and simplicity, in that order | S google-code-review
- Approves when the change makes the code better, even if not perfect | S google-code-review
- Comments are kind, explain why, and mark nits as optional | S google-code-review
- Replies within one working day | S google-code-review

- Main is protected: no direct pushes, checks must pass | S github-protected
