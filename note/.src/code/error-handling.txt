## Catching
- Expected failures (network, invalid input) handled where they happen | S owasp-errors
- An error boundary around each screen so one crash does not blank the app | S react-error
- Errors never swallowed silently | S owasp-errors
## Showing
- People see plain words and a next step, never raw error text | R nng-errors >design-system/content-voice
- Retry offered for temporary failures, with growing waits | S aws-backoff
## Recording
- Every unexpected error logged with context and a request id | S owasp-logging otel >operations/logging
- No passwords or personal data in error reports | S owasp-logging >backend/data-privacy
## Safety
- Failures fail closed: access denied when a check errors | S owasp-scp
