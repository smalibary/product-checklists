## Reading
- Each comment: author, photo, time, text, and actions (reply, edit, delete, react) | P
- Threads: replies grouped under the comment | P
- Edited comments marked "edited" | P
- New comments since last visit marked | P
- Long threads collapse older replies | P
- Sort by oldest or newest | P

- Resolve a thread to hide it; show resolved ones on demand | P
- Re-open a resolved thread | P

- Email replies post back as comments where supported | P
## Rules
- Only the author edits; author and admins delete | S owasp-authz
- Deleted comment leaves "Comment deleted" so replies make sense | P
- Report or hide abuse in public comments | L eu-dsa
- Text escaped so it cannot run code (no script injection) | S owasp-xss >code/secure-coding
