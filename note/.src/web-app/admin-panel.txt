## Navigation
- Side menu grouped by area (Users, Content, Billing, Settings, Logs) | P
- Global search by user, email, ID or order | P
- Clear sign that this is the admin area (colour band, label) | P
- Breadcrumbs for deep pages | R nng-breadcrumbs >design-system/breadcrumb
## Lists and records
- Data tables with search, filter, sort, pagination and export | R nng-tables >web-app/import-export >flows/filtering-items >design-system/pagination
- Bulk actions with a count and a confirm | R nng-confirm
- Record pages show everything about a user or item in one place | P
## Powerful actions
- Each dangerous action (ban, refund, delete) asks for confirmation naming the target | R nng-confirm
- A reason must be typed for sensitive actions, stored in the log | S owasp-logging
- Undo where possible; soft delete before hard delete | R nng-control >flows/undoing-an-action
- "View as user" clearly marked, logged and read-only by default | S owasp-logging owasp-authz >operations/logging
## Security
- Admin roles separated (support, finance, super admin) with least privilege | S owasp-authz >web-app/roles-permissions
- Two-step sign-in required for admins | S owasp-mfa >web-app/2fa
- Shorter session timeout than the main app | S owasp-session >backend/sessions
- Every admin action logged with who, what, when and from where | S owasp-logging >operations/logging
- Personal data shown only where needed; masked by default | L gdpr-25 gdpr-32 >backend/data-privacy
- Restricted by network or device for the most sensitive tools | P
