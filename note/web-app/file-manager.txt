FILE MANAGER CHECKLIST: 12 items
Browsing, organising and sharing files and folders in an app.
Backing: 0 Rule, 6 Standard, 6 Research, 0 Practice
Rule = a store or a law requires it · Standard = a published standard · Research = usability studies · Practice = good practice, no study found

VIEWS
 1. List and grid views, remembering the choice   (Research: nng-tables)
 2. Columns for name, owner, size and date, sortable   (Research: nng-tables)
 3. Breadcrumbs for the folder path   (Research: nng-breadcrumbs)  -> see design-system/breadcrumb

ACTIONS
 4. Upload by button and by dropping files, with progress   (Standard: govuk-file-upload)  -> see design-system/file-upload
 5. Select many with checkboxes, Shift-click and keyboard   (Standard: apg-grid)  -> see design-system/checkbox
 6. Rename, move, copy, delete and share from a menu and from shortcuts   (Standard: apg-menu)
 7. Delete goes to a bin that can be restored   (Research: nng-control)

FEEDBACK
 8. Empty folders explain what to do   (Research: nng-empty)
 9. Long tasks show progress and can be cancelled   (Research: nng-progress)

SHARING
10. Clear who can see each file   (Standard: owasp-authz)  -> see web-app/roles-permissions

ACCESS
11. Drag and drop has a keyboard or menu alternative   (Standard: wcag-dragging)
12. File types shown by icon and text, not icon alone   (Standard: wcag-color)
