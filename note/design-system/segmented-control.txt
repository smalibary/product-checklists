SEGMENTED CONTROL CHECKLIST: 8 items
A row of 2 to 5 joined buttons for switching between views or options.
Backing: 0 Rule, 8 Standard, 0 Research, 0 Practice
Rule = a store or a law requires it · Standard = a published standard · Research = usability studies · Practice = good practice, no study found

USE
 1. For 2 to 5 related choices that switch a view at once   (Standard: hig-segmented, m3-segmented)
 2. Not for navigation between pages; use tabs instead   (Standard: hig-segmented)  -> see design-system/tabs

LABELS
 3. Short text or icons with names, all the same kind   (Standard: hig-segmented)

BEHAVIOUR
 4. One selected at a time, or several when marked as multi-select   (Standard: m3-segmented)
 5. Selection clear by more than colour   (Standard: wcag-color)

SEMANTICS
 6. Built as a radio group or toggle buttons   (Standard: apg-radio)  -> see design-system/radio

LOOK
 7. Equal widths; text does not wrap   (Standard: hig-segmented)
 8. Tap targets large enough   (Standard: wcag-target)  -> see design-system/accessibility

SOURCES
