INTERNATIONAL SEO CHECKLIST: 9 items
Serving the right language version of each page to each searcher.
Backing: 0 Rule, 9 Standard, 0 Research, 0 Practice
Rule = a store or a law requires it · Standard = a published standard · Research = usability studies · Practice = good practice, no study found

ADDRESSES
 1. One address per language (folder or subdomain), never switched by cookie   (Standard: gsc-hreflang)
 2. hreflang links between all versions, each pointing back   (Standard: gsc-hreflang)
 3. An x-default for the language chooser   (Standard: gsc-hreflang)

CONTENT
 4. Whole pages translated, not just menus   (Standard: gsc-hreflang)  -> see design-system/rtl-localisation
 5. Language set in the page's lang attribute   (Standard: wcag-lang)
 6. Right-to-left pages mirrored for Arabic   (Standard: w3c-dir)  -> see design-system/rtl-localisation
 7. Dates, numbers and money in local formats   (Standard: mdn-intl)

CHOICE
 8. No forced redirects by location; offer a switch   (Standard: gsc-hreflang)  -> see flows/switching-language
 9. Each version listed in the sitemap   (Standard: gsc-sitemaps)  -> see growth/technical-seo
